# Sample portfolio

A customizable portfolio built with **JavaScript, React, Vite, and Tailwind CSS**.

## Development

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

## Customize

- `src/App.jsx`: sample profile, project data, and page sections.
- `src/index.css`: theme, responsive layouts, and project preview styling.
- `public/favicon.svg`: personal monogram.
- `index.html`: page title and description.

Alex Morgan and the projects are illustrative sample content. The contact address is `hello@example.com`; replace it before using this as a real portfolio. Project cards open concept descriptions, not external live demos. Project previews are HTML/CSS interface mockups. Fonts load from Google Fonts with local fallback fonts.
